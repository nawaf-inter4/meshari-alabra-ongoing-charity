# After deploying this template

1. Set `NEXT_PUBLIC_SITE_URL` to the final HTTPS origin.
2. Review [WHITE_LABELING.md](./WHITE_LABELING.md) and configure identity, assets, SEO, content, PWA, and colors.
3. Store private values only in the hosting provider's environment settings.
4. Never place secrets in a `NEXT_PUBLIC_*` variable.
5. Verify `/manifest.webmanifest`, PWA installation, social previews, donation links, and YouTube playback.
6. Run the application in a fork before making memorial content public.
