# iOS PWA splash images

These PNGs are referenced by `apple-touch-startup-image` links (see `src/lib/apple-splash.ts` and `AppleSplashLinks`).

Regenerate after icon or brand-color changes:

```bash
npm run generate:splash
```

Background: site dark memorial slate (`#0F172A`) with a soft gold wash.
