## 📐 Screen Size Adaptations

### 📱 Mobile Phone (< 768px)
- **Fonts**: 14-18px
- **Padding**: 12-16px
- **Touch Targets**: 44px minimum
- **Layout**: Single column
- **Icons**: 20-24px

### 📱 Tablet (768px - 1024px)
- **Fonts**: 16-24px
- **Padding**: 16-24px
- **Touch Targets**: 56px minimum
- **Layout**: Can use 2 columns
- **Icons**: 24-28px

### 📺 TV (> 1920px)
- **Fonts**: 24-48px
- **Padding**: 32-64px
- **Touch Targets**: 100px minimum
- **Layout**: Large cards, focus-based
- **Icons**: 32-48px

### ⌚ Watch (< 200px)
- **Fonts**: 10-16px
- **Padding**: 4-8px
- **Touch Targets**: 44px minimum
- **Layout**: Compact, essential only
- **Icons**: 16-20px
